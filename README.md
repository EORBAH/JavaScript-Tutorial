# JavaScript Tutorial

A comprehensive guide to learning JavaScript, from basics to advanced concepts, including practical projects.

## Structure
- **docs/**: Tutorial content split into sections.
- **examples/**: Code snippets demonstrating each concept.
- **projects/**: Complete applications (To-Do List, Calculator, Memory Game).
- **LICENSE**: MIT License for usage.

## Getting Started
1. Clone or download this repository.
2. Open `01_introduction.md` for the tutorial content.
3. Run examples in `examples/` using a browser or Node.js.
4. Explore projects in `projects/` by opening `index.html` files in a browser.

## Prerequisites
- A modern web browser (e.g., Chrome, Firefox).
- Optional: Node.js for running scripts outside the browser.
- A code editor like Visual Studio Code.
