# 1. Introduction à JavaScript

## Qu'est-ce que JavaScript ?
JavaScript est un langage de programmation **interprété**, **dynamique**, et **polyvalent**, principalement utilisé pour rendre les pages web interactives. Créé en 1995 par Brendan Eich, il est aujourd'hui un pilier du développement web, utilisé côté client (navigateurs) et côté serveur (via Node.js). Voici ses caractéristiques principales :
- **Typage dynamique** : Pas besoin de déclarer le type d'une variable.
- **Basé sur des prototypes** : Les objets héritent directement des propriétés d'autres objets.
- **Événementiel** : Idéal pour gérer des interactions utilisateur.
- **Écosystème riche** : Utilisé dans des frameworks comme React, Angular, et Node.js.

## Pourquoi apprendre JavaScript ?
- **Polyvalence** : Web, applications mobiles, jeux, etc.
- **Demande élevée** : Très recherché par les employeurs.
- **Communauté active** : Nombreuses ressources disponibles.

## Exemple simple
```javascript
console.log("Bienvenue dans JavaScript !");
```

**Analogie** : JavaScript est comme un chef cuisinier dans un restaurant (la page web), préparant des plats (contenu dynamique) et répondant aux commandes (événements).
