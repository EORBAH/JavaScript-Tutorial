# 3.4 Fonctions

## Définition
Bloc de code réutilisable exécutant une tâche.

## Types
```javascript
function saluer(nom) {
    return `Bonjour, ${nom} !`;
}
const addition = (a, b) => a + b;
console.log(saluer("Alice")); // Bonjour, Alice !
console.log(addition(3, 7)); // 10
```

**Exercices**
1. Créez une fonction qui renverse une chaîne.
2. Créez une fonction qui trouve le plus grand nombre dans un tableau.
