# 3.3 Structures de contrôle

## Définition
Gèrent le flux du programme (décisions, répétitions).

## Conditions
```javascript
let note = 85;
if (note >= 90) {
    console.log("Excellent");
} else if (note >= 70) {
    console.log("Bien");
} else {
    console.log("À améliorer");
}
```

## Boucles
```javascript
for (let i = 1; i <= 5; i++) {
    console.log(i); // 1, 2, 3, 4, 5
}
```

**Exercices**
