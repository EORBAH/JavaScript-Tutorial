# 3.2 Opérateurs

## Définition
Les opérateurs manipulent des données (calculs, comparaisons).

## Types
1. **Arithmétiques** : `+`, `-`, `*`, `/`, `%`, `**`.
2. **Affectation** : `=`, `+=`, `-=`, etc.
3. **Comparaison** : `==`, `===`, `!=`, `!==`, `>`, `<`.
4. **Logiques** : `&&`, `||`, `!`.

## Exemples
```javascript
let a = 10, b = 3;
console.log(a + b); // 13
console.log(a % b); // 1
console.log(a === b); // false
console.log(a >= 10 && b < 5); // true
```

**Exercices**
1. Calculez l’aire d’un cercle (π * rayon², utilisez `Math.PI`).
